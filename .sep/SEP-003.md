# SEP-003: Fix Lambda lxml darwin binary breaking all RSS feeds

**Status:** Open
**Created:** 2026-03-19
**Project:** newsroom

## Summary
The deploy script installs macOS-compiled lxml into the Lambda package, which runs on Linux. This causes all XML/RSS parsing to fall back to html.parser, which treats <link> as a void element and discards all article URLs, resulting in 0 articles from every feed.

## Motivation
Article count dropped from 514 to ~29 after a macOS deploy bundled darwin .so files. The scraper has been broken since mid-January 2026.

## Proposed Change
Fix deploy_lambda.sh to install Linux-compatible binaries using pip --platform flags. No scraper logic changes needed.

## Acceptance Criteria
Lambda deploys with Linux-compatible lxml, feeds return >50 articles per run
